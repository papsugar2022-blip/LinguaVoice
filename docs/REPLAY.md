# 聊天内重播（0.3.4 预览版）

2026-11-24 已在普通 ChatGPT 桌面聊天实际验证：声音合成后由本机播放器播放；聊天中出现“再听一遍”卡片；点击卡片后，同一段录音再次播放完成。重播前后合成任务数不变。验收依据是实际界面点击与后台播放记录，不是聊天模型声称“已显示”。机器可读实测记录保存在本机 private/replay-verification.json，不随开源包导出。

## 正确的连接方式

普通 ChatGPT 聊天使用用户自己的安全隧道连接。Work / Codex 的本地插件是另一种连接方式，不是新版替代品。在本次客户端中，本地插件虽然出现在普通聊天的 @ 候选中，但普通聊天发现不到其工具。不能因为它名字相同就卸载原来的安全连接。连接向导默认显示“普通 ChatGPT 聊天”，另一个标签明确标为“Work / Codex 本地模式”。

该电脑已移除本地重复入口，保留原来可在普通聊天调用的连接。声音模型、角色绑定、默认音色和语速均未替换。首次使用仍需账号支持相应的自定义连接；免费账号与手机端未验收。

## 播放卡片

MCP Apps 使用 ui://linguavoice/replay-v3.html；旧版 ChatGPT 输出模板使用 ui://linguavoice/replay-chatgpt-v3.html，分别提供对应的 MIME 类型和消息桥接方式。v1/v2 资源保留供旧客户端兼容。卡片只包含程序界面，不含密钥、音频、用户原文或角色资源。卡片从工具结果取得本段录音编号，通过既有认证连接请求重播，不直接暴露本机接口。

每张卡片固定绑定首次收到的合法录音编号。后续其他录音结果不会把旧卡片重新绑定到最新一句。点击等待期间防止重复提交；15 秒未确认只提示等待，继续接收最长 120 秒内的回复，不把网络确认慢误报为播放失败；后台关闭或录音已过期时显示错误，不静默重新合成。打开卡片本身不自动重播。服务重启或历史清理后，旧任务可能无法播放。

linguavoice_speak 和 linguavoice_get_audio 返回播放卡片；linguavoice_show_player 可为本对话已有录音补充卡片，只读取元数据。linguavoice_replay 仅把已有录音加入播放队列。queued 不代表用户已经听到声音，也不代表播放完成。

## 更新与验证

保持相同的插件和隧道身份。更新本机 MCP 服务并重启其连接进程后，在 ChatGPT 的该插件设置中点击“刷新工具”，让客户端重新登记工具及界面资源，再在普通聊天中验证。此次旧卡片曾报 Unknown resource；更换界面资源版本并刷新后，普通聊天成功加载卡片。不要以 Work 中的成功替代普通聊天验收，不要通过重装模型排查界面资源缓存。

本次通过 26 项 Python 测试、标准 MCP Apps 和 ChatGPT 兼容桥接按钮测试，并实际点过普通聊天的重播按钮。基本操作：通过 @ 选择 LinguaVoice 后正常聊天，无需额外启用口令；点击对应录音旁的绿色“再听一遍”。用户明确要求单次试听时仍遵守单次限制。

ChatGPT 桌面程序关闭窗口后重开曾出现 Connection for host ID local not found。修复连接后一次关闭重开检查未出现该错误，但本次未修改官方程序，不能据此声称客户端生命周期故障已经根治。
