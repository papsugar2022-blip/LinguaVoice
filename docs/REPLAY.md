# 聊天内重播（0.3.11 预览版）

2026-11-24 已在普通 ChatGPT 桌面聊天实际验证：声音合成后由本机播放器播放；聊天中出现“再听一遍”卡片；点击卡片后，同一段录音再次播放完成。重播前后合成任务数不变。验收依据是实际界面点击与后台播放记录，不是聊天模型声称“已显示”。机器可读实测记录保存在本机 private/replay-verification.json，不随开源包导出。

## 正确的连接方式

普通 ChatGPT 聊天使用用户自己的安全隧道连接。Work / Codex 的本地插件是另一种连接方式，不是新版替代品。在本次客户端中，本地插件虽然出现在普通聊天的 @ 候选中，但普通聊天发现不到其工具。不能因为它名字相同就卸载原来的安全连接。连接向导默认显示“普通 ChatGPT 聊天”，另一个标签明确标为“Work / Codex 本地模式”。

该电脑已移除本地重复入口，保留原来可在普通聊天调用的连接。声音模型、角色绑定、默认音色和语速均未替换。首次使用仍需账号支持相应的自定义连接；免费账号与手机端未验收。

## 播放卡片

MCP Apps 使用 ui://linguavoice/replay-v5.html；旧版 ChatGPT 输出模板使用 ui://linguavoice/replay-chatgpt-v5.html，分别提供对应的 MIME 类型和消息桥接方式。v1/v2/v3 资源保留供旧客户端兼容。卡片只包含程序界面，不含密钥、音频、用户原文或角色资源。卡片从工具结果取得本段录音编号，通过既有认证连接请求重播，不直接暴露本机接口。

每张卡片固定绑定首次收到的合法录音编号。后续其他录音结果不会把旧卡片重新绑定到最新一句。点击等待期间防止重复提交；15 秒未确认只提示等待，继续接收最长 120 秒内的回复，不把网络确认慢误报为播放失败；后台关闭或录音已过期时显示错误，不静默重新合成。打开卡片本身不自动重播。服务重启会恢复最近 80 个仍保留音频的成功任务，不自动播放；历史清理或音频文件被删除后，旧任务可能无法播放。

linguavoice_speak 和 linguavoice_get_audio 返回播放卡片；linguavoice_show_player 可为本对话已有录音补充卡片，只读取元数据。linguavoice_replay 仅把已有录音加入播放队列。queued 不代表用户已经听到声音，也不代表播放完成。

## 更新与验证

保持相同的插件和隧道身份。更新本机 MCP 服务并重启其连接进程后，在 ChatGPT 的该插件设置中点击“刷新工具”，让客户端重新登记工具及界面资源，再在普通聊天中验证。此次旧卡片曾报 Unknown resource；更换界面资源版本并刷新后，普通聊天成功加载卡片。不要以 Work 中的成功替代普通聊天验收，不要通过重装模型排查界面资源缓存。

本次通过 26 项 Python 测试、标准 MCP Apps 和 ChatGPT 兼容桥接按钮测试，并实际点过普通聊天的重播按钮。基本操作：通过 @ 选择 LinguaVoice 后正常聊天，无需额外启用口令；点击对应录音旁的绿色“再听一遍”。用户明确要求单次试听时仍遵守单次限制。

ChatGPT 桌面程序关闭窗口后重开曾出现 Connection for host ID local not found。修复连接后一次关闭重开检查未出现该错误，但本次未修改官方程序，不能据此声称客户端生命周期故障已经根治。

## 分段提示与暂停（0.3.11）

2026-11-28 在普通 ChatGPT 的“语音测试完成”聊天实际验证：三段中英混合真实合成后，点击重播，卡片从第 1 段推进，点击暂停后显示“已暂停 · 第 2 / 3 段”，点击继续后显示“正在读 · 第 2 / 3 段”。共 37 项 Python 测试和两组 JavaScript 测试通过。未据此宣称手机或其他账号已通过。

默认段间静音 0.45 秒，网页可设置为 0、0.25、0.45、0.75、1 秒；仅影响新录音。分段由 AI 已选台词中的换行及句末边界确定，不负责选择朗读内容。每段保留完整文字，以真实音频采样长度记录起止位置，播放器按实际播放帧报告进度。分段推理可能增加合成耗时，首次模型加载尤其明显。

“显示正在朗读的内容”控制卡片和网页提示，关闭不影响暂停按钮。听力隐藏原文时不返回当前句子。旧录音没有分段时间信息，可继续重播，但不会伪造段落提示。

卡片状态和暂停/继续使用仅应用可见的工具，不触发新的模型回复。当前朗读文字仅经工具结果 _meta 提供给界面；普通工具结果保持简短，不回传音频或全部讲义。状态查询只针对该卡片的录音，不读取聊天历史。控制工具拒绝暂停另一张卡片正在播放的语音。

更新后须在 ChatGPT → LinguaVoice 设置 → 刷新工具，登记两个新增的卡片接口。只重启本机服务而未刷新时，卡片可能提示接口不存在；请刷新后点击重播或重新打开卡片，无需卸载原连接、删除音色或重装模型。
