# 接入 ChatGPT

核查日期：2026-11-24。

## 桌面本地插件

安装器准备好声音后，注册随附的本地插件源，在桌面插件列表安装 LinguaVoice。插件使用本机安装目录启动 MCP，账号密钥不会写入插件包。第一次需安装插件；后续打开支持本地插件的会话即可调用。插件修改后新建会话以加载更新。

该路线受本地插件入口及会话能力限制，不代表所有 ChatGPT 普通对话都可使用。免费账号需实际登录验收，不能仅根据套餐文档作保证。

## 私人安全隧道

已有自定义 MCP 接口的账号可用安装器的连接向导，填写自己的 OpenAI 连接编号及运行密钥。密钥只在本机使用，可由 Windows DPAPI 加密保存。服务器仍监听回环地址，不开放无认证公网端口。不要把个人连接编号、密钥和插件绑定打包发给别人。

首次连接需要账号本身提供相应入口；安装器不能替用户开通权限。当前电脑上的既有私人插件仍保留。

## 连续表达

启用角色语音后，技能要求后续每轮按语境判断，无需每句 @。AI 仍可能漏调工具，不能宣称程序能强制控制 ChatGPT 的决策。先显示普通聊天台词，再调用合成，避免语音抢在正文之前。听力题隐藏答案时例外。

插件只能获得 AI 主动传入的台词和参数，不能私自读取全部聊天、记忆或原生朗读按钮。模型负责语义选择；TTS 只负责执行。工具级成功不等于连续对话已验收。

## 手机与免费账号

桌面本地插件不支持手机。远程 MCP 可返回真实音频，但手机是否显示音频、允许自动播放、持续触发工具，需分别实测；当前未交付手机闭环。不会把独立网页冒充 ChatGPT 手机插件。
