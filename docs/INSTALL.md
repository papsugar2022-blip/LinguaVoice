# 安装与导入

安装器使用独立 Python，不修改系统 PATH、不修改其他工程。已有安装保留 private/ 中的声音、账号和设置。两项支持可独立勾选：默认勾选“自定义导入（V5Turbo 声音包）”，只装 GPT-SoVITS V5Turbo 所需组件；“自带声音（作者自制：秋猫）”按需勾选，才下载 Qwen3-TTS 模型及运行环境。也可以两项都选。未勾选不会卸载已有组件和声音。

“自定义导入”不附带第三方角色模型，需要用户自行取得获准使用的 V5Turbo 角色 ZIP。“自带声音”中的秋猫由作者使用文字描述生成参考音色，并非单独训练的微调权重，来源见 assets/default-voice/SOURCE.md。

第一次下载体积较大。支持分块续传、大小和 SHA256 校验。停止安装保留下载进度，再次安装会校验后继续。失败详情在 private/setup.log。

勾选秋猫时，安装完成前会实际生成秋猫声音并检查输出设备。只选 V5 时检查所需组件；已有 V5 音色则实际合成，没有音色时明确提示“等待导入”，不会下载秋猫充当测试声音，也不会宣称语音合成已验证。这些检查不证明 ChatGPT 已连接或音质已被用户接受。

## 角色 ZIP

- 标准包：config.json、models/gpt.ckpt、models/sovits.pth、参考录音、.list 台词标注。
- 普通单角色包：一对 .ckpt/.pth 与参考音频、.list 标注；完整中文台词作为音频文件名时可读取作参考文字。
- 同系列有多轮权重时选择最高轮次并显示实际选用文件；轮次最高不表示音质最好。多个角色或无法明确配对时拒绝，要求每包一对。
- 参考录音需 3～10 秒，台词与录音一致。不能把只有录音或 RVC 权重当作 GPT-SoVITS 模型。
- 上传最大 1 GB、展开最大 3 GB，拒绝越界路径和链接。相同 ZIP 按内容去重。

模型可能包含可执行的序列化内容，仅导入可信来源。安装或修改显示名字不产生版权授权。模型原作者、原始录音、角色相关权利分别确认；程序 MIT 不覆盖这些资源。

默认音色只用于没有指定其他角色时；已指定但未绑定的角色不会自动替换声音。新导入声音不会替换现有默认设置。

## 参考声音 ZIP

Qwen3-TTS 使用 voice.json 清单加参考录音，格式见 API 文档。可导入自己录制或获得授权的声音，无需把它伪装成 GPT-SoVITS 权重。默认秋猫也提供同格式示例包。
