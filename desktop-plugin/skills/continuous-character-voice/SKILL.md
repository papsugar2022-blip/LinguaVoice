# 持续角色语音

这是当前对话角色的表达技能，配合本插件已连接的 LinguaVoice MCP 工具。保持角色原有性格、称呼、记忆和教学方式。

## 保持当前对话的使用意图

用户在输入框通过 @ 选择本插件并发送普通聊天或教学消息，即表示在当前对话启用角色语音；不要求另发启用口令。仅询问安装、排障、设置或要求停止播放时，按该操作处理，不因此启动持续朗读。

用户在当前对话启用角色语音后，把它视为持续的对话偏好，直到用户要求关闭或改为纯文字。之后用户省略 @、插件名、“朗读”或“说出来”，不代表关闭。每轮结合对话上下文主动判断哪些内容适合亲口说，不让用户逐句复制、选文本或重新 @。这不表示每条回复必须有声音：安静、无合适台词或语音无帮助时可以不调用。不要在其他对话推定用户已启用。

用户说“停止播放”时，调用 linguavoice_playback 的 stop，只停止当前播放，不关闭以后聊天的语音，也不合成停止确认。用户要求以后不再发声时，在本段对话遵守该偏好；全局关闭可打开网页设置，关闭“让 AI 说话”。用户恢复后继续主动判断。网页关闭语音设置优先；不要因 @ 擅自重新开启。

## 每轮的表达顺序

1. 根据语义组织完整的文字回复和适合说出口的台词。日常聊天、问候、关心和中文解释也可以自然说话。动作、神态、场景旁白、标题、角色标签、列表编号和幕后说明通常只显示文字；不要按语言、引号、括号或正则机械过滤。
2. 普通聊天先在用户可见的回复中输出本轮真正的角色台词，再调用语音工具。宿主支持工具前可见消息时，把角色回复放在那里；不要只写“我来生成语音”，不要把台词仅放进工具参数，也不要把全部正文留到语音生成后的最终回复。文字和声音可按表达方式有所区别，但事实、否定和承诺必须一致。
3. 使用实际可用的工具发现/选择能力找到本插件的 linguavoice_list_voices 和 linguavoice_speak。先确认全局音色和设置；缓存仍适用时无需每轮重复查询。使用 linguavoice_speak 发送已选好的完整台词，每段不超过 400 字。不要拆成每词一次，不重复提交同一句。
4. 工具完成后不要再重复整段已显示台词；只有需要时补充简短文字或处理错误。不要把“已合成”说成“已播放”。
5. 听力测试是有意先语音的例外：只先显示任务提示，hide_text=true，暂不显示原文和答案。工具参数可能仍被客户端展示，不承诺完全保密。

本机播放器按合成完成自动播放；插件无法获知 ChatGPT 最终正文何时绘制完成。以上先文字后工具的顺序是模型执行约定，不是逐字同步保证。如果宿主不显示工具前正文，或未给本轮提供工具，明确说明限制；不要谎称已播放、不要虚构调用、不要用固定等待秒数冒充同步。工具暂时缺失时按宿主支持的发现方式查找；不能要求用户每句重新 @ 来充当完成方案。

## 角色的代码与数学教学

角色讲解代码或数学时，代码、命令、公式与完整推导仍展示在文字中，语音主要讲解思路、步骤和结论；默认不逐行念代码、不逐个念符号或 LaTeX。根据上下文自然用“这个函数”“上面这段”“这里的变量”“这个式子”“左边这一项”“把它代进去”等指代；指向应清楚，必要的数字、条件、单位和结论可以自然说出，不能为省略而改变意思或造成歧义。用户明确要求朗读具体代码或公式时才按要求读。这是对话 AI 的语义表达选择，不通过正则删除代码块或公式，不把全部书面讲义送去朗读。

## 教学语音覆盖

教学语音要覆盖实际教学内容，不能只朗读问候、安慰、过渡语或最后一句总结。语音已启用且用户正在学词汇、句子或知识点时，应读出正在讲的目标单词或短语、核心含义或用法解释、关键例句，以及必要的推理和学习提示。只看语音也应能跟上这次讲解。列表中的单词、加粗的例句仍是教学内容，不因排版被省略。按语义组织自然口头讲解，不要求全文照读，不用固定比例或语言规则选句。

单词教学应实际发出单词本身，不能只读中文释义。可以把同一组词放在一段，例如“exceptional，非凡的。endeavor，努力或尝试。”英文示范句保持原文；纯英文示范使用 language=en，中文夹英文的解释使用 language=zh。必要时把英文示范与中文讲解按意义分成多次调用，每段不超过400字；不要为少调用而删掉本轮教学重点。单个词本身就是本轮发音任务时允许单独调用，不把整句机械拆成每词调用。

普通教学先显示文字再按顺序发声。听力测试按隐藏原文要求，纯阅读或测验不该泄露答案时遵守教学目的，用户要求不读时保持安静。代码、公式和动作标题仍按原有原则处理；代码数学的口头思路、关键步骤、条件和结论要讲完整，不缩成一句泛泛鼓励。

## 音色与控制

所有对话统一使用网页选中的全局音色，旧角色绑定及工具中的 role、voice_id 不覆盖它；没有角色绑定也可正常调用。角色性格仍按对话设定。V5 Turbo 统一使用 J 参数，不改写原权重或参考录音。语言及语速遵从用户偏好和教学意图，不硬禁中文。正常、慢速、分段、重复只用工具实际支持的参数。

需要设置或导入模型时调用 linguavoice_open_console；暂停、继续、停止用 linguavoice_playback。用户说“再听一遍”“重播上一句”时，用 linguavoice_replay，job_id 取本对话上一段 speak/get_audio 返回的 id；指定更早的一段时使用对应 id。无需用户填写编号，不调用 speak 重新合成，不把其他对话或网页试听的最近一段当作本对话上一句。若本对话没有可用的语音记录，说明原因并询问想听哪段，不猜测编号。排队不等于播放完成。后台播放关闭时保留其设置，可用 get_audio 返回已有音频供用户手动播放，不擅自开启。不要读取完整聊天记录、账户凭据或控制 ChatGPT 原生朗读按钮。

## 找不到重播按钮时

用本对话已有的任务 id 调用 linguavoice_show_player，专门返回播放卡片；不重新合成、不要求用户手填编号。不要仅回复“按钮已经有了”，也不要用原生朗读图标冒充私人音色重播。卡片资源返回成功不等于宿主已向用户展示。若由另一个执行器代为调用，保留工具返回的卡片及任务 id，不要只交回一段完成摘要；宿主无法传递界面时应说明限制，不擅自改成独立网页。

## 验收边界

发布此技能不等于已通过连续聊天验收。需要在用户实际使用的 ChatGPT 对话验证：启用一次后至少三轮不 @ 的自然交流仍会按语境调用；动作与标题不被读出；普通聊天文字先出现；关闭语音后停止；听力原文暂隐藏。只有真实客户端和播放记录支持时才能说通过。
