**v0.3.8 预览版 · Windows / NVIDIA · 自定义导入 / 自带声音自由勾选**

本次修复：语音工具仅返回简短状态和重播编号，所有播放模式均不再向聊天回传 WAV / base64 音频（包括旧参数调用）。电脑自动播放、暂停和重播保留；网页仍可播放原录音。此修复减少工具结果负担，不能自动恢复已达到长度上限的旧聊天，也不能保证永远不会达到平台限制。

当前为开发预览版：已有电脑上的真实语音合成与播放已验证；全新电脑完整安装、免费 ChatGPT 账号和手机端尚未完成验收。请勿将“可下载安装器”理解为所有账号安装即用。

安装器与源码见仓库的 **Releases** 页面。安装器约 12 MB；首次运行仅下载勾选的引擎和底模。默认勾选“自定义导入（V5Turbo 声音包）”；需要秋猫时，另勾选“自带声音（作者自制：秋猫）”。只选 V5 不下载 Qwen 模型及其运行环境。空间提示包含解压缓存，不是下载量。

让 ChatGPT 自己选择需要说的话，用你选好的声音聊天和教学。文字与语音独立：代码、公式、标题和动作描写通常只显示，语音自然解释思路。无需逐句复制台词。

自带声音为秋猫，来自作者用文字描述生成的参考音色，并非单独训练的微调权重。自定义导入需自行取得获准使用的声音包；第三方角色模型与录音不随本项目发布。原有私人声音与设置在本机保留。

## Windows 使用

1. 运行“LinguaVoice-安装器.exe”，勾选需要的声音支持，选择安装目录，点“安装 / 检查修复”。需要 NVIDIA 显卡和联网；按所选组件预留安装空间，本机测试为 RTX 5070 Laptop 8 GB。
2. 点“网页设置”：自定义导入用户先拖入获准使用的 V5Turbo 角色 ZIP；勾选自带秋猫时已包含可试听的参考音色。
3. 首次使用点“首次连接 / 修复”。普通聊天使用“高级：首次连接 / 修复”里的私人安全连接；Work / Codex 本地模式在另一标签。两者不是新旧版本，已有可用连接请保留。首次安装、账号授权不能由安装器绕过。
4. 日常直接打开 ChatGPT，输入 `@`，从列表选择 LinguaVoice，再发送想聊的话；无需额外启用口令。同一聊天后续正常交流，新聊天再选择一次。网页开启“登录电脑后自动准备”后，不用每天开安装器。
5. 只停当前声音：在聊天里说“停止播放”，或点网页的“停止播放”。关闭后续语音：网页关闭“让 AI 说话”；重新打开即可恢复。

其他声音：勾选安装器里的 GPT-SoVITS 可选引擎，再把有权使用的单角色 ZIP 拖到网页。来源不明、含多个角色或缺少参考台词的包会提示原因，不会冒用别的声音。

## 支持范围

当前精简版只保留 V5Turbo + 秋猫，不安装 V3/V4 组件。已有私人文件不会被删除。

| 引擎 | 接入情况 |
|---|---|
| Qwen3-TTS 0.6B Base | 默认声音，中文及英文已真实生成；其余语言需逐项试听 |
| GPT-SoVITS V5Turbo | 已真实生成，保留各声音自己的参数 |
| 其他 GPT-SoVITS 版本 / RVC | 可识别部分格式，不宣称可合成 |

支持语速 0.6～1.5、自动播放开关、暂停、继续、停止、重播、全局统一音色、隐藏听力原文和设置备份。隐藏原文不保证客户端工具参数不可见。

本机普通 ChatGPT 桌面聊天已实际验证绿色“再听一遍”卡片，点击可重播对应录音，无需重新合成。连接更新后在插件设置中刷新工具与界面资源。详见 [重播说明](docs/REPLAY.md)。

## 平台边界

本地插件仅适用于可运行本地工具的桌面会话。账号、客户端、插件入口和额度决定能否调用；免费账号尚未实际验收，不能承诺所有免费用户安装即用。手机端尚未验收，桌面播放不会自动变成手机播放。电脑关机后本地合成不可用；云端后端接口可扩展，但当前未交付云托管服务。

GitHub 源码发布不等于进入官方插件目录。官方本地插件上架有额外资格和审核要求。见 [ChatGPT 接入说明](docs/CHATGPT.md)。

## 开发与验证

源码可放在独立目录；不要把整个本机工程直接上传。控制台仅监听 127.0.0.1，使用随机令牌并校验来源。密钥、模型、角色录音、对话输出在 private/，不进入源码发布包。

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests
node tests/test_upload_ui.js
.\.venv\Scripts\python.exe scripts/verify_install.py
.\.venv\Scripts\python.exe tests/integration_mcp.py
```

真实合成测试需要模型与 GPU。普通单元测试不产生模拟试听音频。引擎依赖在独立进程中运行，避免不同版本冲突；切换后端会释放旧进程的显存。
